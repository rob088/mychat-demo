# MyChat (Demo)

**Demo mit Testdaten, keine echten Zahlungen.**

Standalone-Vorschau der App MyChat (Chat, MyMap, MyWallet).

Anmeldung: ein Demo-Konto antippen (z. B. Lena), Code `123456`. Es wird keine SMS verschickt. Alle Daten sind fiktiv.

Diese Seite läuft ohne eigenes Backend; die Demo-API steckt in der HTML-Datei.
